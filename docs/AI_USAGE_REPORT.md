**AI OUTPUT THAT WAS WRONG:**

1. **Form reset bug (ai-log #6).** After the duplicate-request warning, "create anyway" failed with "Choose a category." React 19 automatically resets a form after a server action, which blanked the category `<select>`. The AI's first fix (make the select controlled) was **also wrong**: the reset clears controlled selects too.
2. **Wrong deployment region (ai-log #13).** Functions went to Vercel's default US East region while the database is in Sydney, so every query crossed the Pacific and cold page loads took more than 30 s.
3. **Tailwind v3 syntax in a v4 project (ai-log #11).** `grid-cols-[auto,1fr]` silently generated no CSS, so the dashboard bars and the details panel lost their column layout.

(Other real errors: an ignored plan limit on cron frequency, a dev server that hangs in a OneDrive folder, feedback messages that unmounted with their buttons, and flaky e2e timing. See ai-log.md.)

**HOW I IDENTIFIED THE PROBLEM:**

1. The end-to-end Playwright test timed out waiting for the redirect. A small debug script printed the field values right after the warning: `category=` was empty while `subject` kept its value. After the first fix, a rerun showed React state still held "FEES" (the hint text was right) but the DOM select was blank.
2. The production run of the same e2e test timed out on the first login. I compared `vercel inspect` (functions in `[iad1]`) with the database host (`…ap-southeast-2.pooler.supabase.com`).
3. By reviewing the Playwright screenshots rather than trusting a green build: the Details panel and chart rows were stacked instead of side by side.

**HOW I FIXED IT:**

1. The form now submits through `onSubmit` + `startTransition(() => action(new FormData(form, submitter)))`, which skips the automatic reset. The e2e test covers the duplicate → create-anyway path.
2. Added `"regions": ["syd1"]` to `vercel.json`, redeployed, and re-ran all 15 production checks. They passed.
3. Switched to Tailwind v4 syntax (`grid-cols-[auto_1fr]`) and re-took the screenshots.
